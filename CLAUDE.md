# CLAUDE.md
Project Context
Informatics student portfolio project for agriculture-tech job applications.
Optimize for clarity and teachability, not cleverness.

Interview-First Coding
- Prefer simple, readable code the student can walk through on a whiteboard.
- Prefer clear names over short names.
- Prefer straightforward control flow over clever abstractions.
- Do not use advanced patterns unless they already exist in the repo and are necessary.
- Do not add layers for “enterprise best practice” (extra interfaces, factories, event buses, DI frameworks beyond Spring’s defaults).
- Keep methods short and purpose-obvious.
- Do not add new languages, frameworks, brokers, or databases beyond modules listed in ARCHITECTURE.md.

Response Style
Prefer brevity. Avoid unnecessary explanations, restatements, or filler unless the user explicitly asks for more detail.
